# FikaClip 최종 비교 기록

## 관찰 범위

로그인된 FikaClip 편집기와 로컬 SkyClip 편집기를 같은 브라우저 세션에서 접근성 트리와 화면 흐름 기준으로 비교했다.

## 차이와 조치

| 영역 | FikaClip 관찰 | SkyClip 현재 상태 | 조치 |
|---|---|---|---|
| 자막 | 시간 구간·단어 단위 표시, 구간별 재생성 버튼 | 시간 구간·단어 표시, 선택 클립 STT 재생성, Tiny/Base/Small/Medium 선택 | 기존 깨진 자막을 선택 클립 원본 기준으로 재생성하고 모델 선택 경계를 노출 |
| 제목 스타일 | 편집/스타일/위치 탭, 폰트·색상·크기·자간·줄간격·그림자·배경·외곽선 | 제목 스타일 저장과 MP4 반영 | 제목 스타일 입력값과 렌더러 연결 |
| 타임라인 | 자르기·삭제·구간 추가·확대/축소·정렬·전환 추가 | 컷 추가·삭제·분할·길이 조절·순서 변경·확대/축소 | 현재 위치 기준 컷 조작과 재진입 저장 추가 |
| 결과→편집 흐름 | 선택 결과가 편집기로 이어지고 제목/자막/미리보기 동기화 | 동일 흐름과 선택 상태 저장 | E2E에서 선택→편집→내보내기 검증 |
| 내보내기 | 다운로드/자동 저장/내보내기 상태 | 실제 MP4 생성·진행률·실패 상태·다운로드 | H.264/AAC 720×1280, HTTP 200 확인 |

## 남은 차이

- FikaClip의 의미 기반 하이라이트와 점수 모델은 로컬 오디오·장면 휴리스틱과 동일하지 않다.
- FikaClip의 구간별 전환효과·다중 트랙·훅 인트로 삽입은 아직 완전 동등하지 않다.
- 외부 AI 번역/이미지/음성/음악 생성 API는 연결 경계만 정의되어 있다.
- FikaClip과 픽셀 단위로 동일한 UI가 아니라, 사용자 흐름과 조작 목적을 독립 구현한 상태다.
