# 골인 기준 검증 체크리스트

이 문서는 기능이 화면에 존재하는지만 세지 않고, 실제 영상으로 사용자 흐름을 통과했을 때만 완료 처리한다.

| 단계 | 통과 조건 | 현재 판정 |
|---|---|---|
| 1. 분석 | FikaClip의 대시보드·결과·편집기 흐름과 URL/상태를 관찰하고 명세에 기록 | 부분 통과 |
| 2. 명세 | SkyClip 독립 데이터 모델과 관찰 근거가 문서화됨 | 부분 통과 |
| 3. 입력/분석 | 파일·공개 링크 입력 후 실제 프로젝트가 완료 상태가 됨 | 통과 |
| 4. 결과 | 5개 이상 실제 MP4, 9:16 미리보기, 썸네일, 자막, 점수 근거가 존재 | 통과(기초 지표) |
| 5. 상세 | 클립 선택, 자막·제목·공유·다운로드가 선택 클립 기준으로 동작 | 기본 통과 |
| 6. AI 편집 | 제목·텍스트·자막·무음·레이아웃 도구가 상태와 렌더링에 연결 | 부분 통과 |
| 7. 편집기 | 캡션 드래그, 구간, 실행 취소/다시 실행, 템플릿/에셋이 재진입 후 유지 | 부분 통과 |
| 8. 내보내기 | 제목·자막·텍스트·효과·구간이 실제 MP4에 반영되고 다운로드됨 | 기본 통과 |
| 9. 비교 | FikaClip과 동일 입력을 사용해 흐름/화면/결과 차이를 기록하고 수정 | 미완료 |
| 10. 릴리스 | 통합 검증, 문서 정리, 커밋, 원격 반영 | 진행 중 |

현재 골인 기준 진척률은 60%다. 실제 동작을 통과한 3~8단계와 릴리스 자동화 반영분을 포함한 가중치 기준이며, `npm run test:acceptance`는 저장된 완료 프로젝트의 실제 준비 클립 상태를 반복 검증한다.
