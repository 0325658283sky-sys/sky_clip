# FikaClip 사용자 흐름 관찰 명세 v2

이 문서는 FikaClip의 로그인된 사용자 화면을 관찰한 결과를 사용자 경험 관점에서 정리한 것이다. 원본 소스, 번들, 비공개 API, 자산은 사용하지 않는다.

## 관찰 근거

- 결과 화면: 생성 클립 목록, 점수, 점수 평가 탭, 세로형 미리보기, 자막/스크립트, 편집·공유·다운로드
- 편집기: 9:16 캔버스, 좌측 자막 세그먼트, 우측 제목/스타일/위치 패널, 하단 영상·자막 타임라인
- 상태: 자동 저장, 저장하기, 내보내기, 실행 취소/다시 실행, 재생 위치, 구간 추가

## 사용자 흐름

```text
대시보드
  → 영상 파일 또는 링크 입력
  → 분석 진행 상태
  → 생성 클립 목록
  → 클립 선택
  → 세로형 미리보기와 점수 확인
  → 자막·제목·스크립트 확인
  → 편집기 진입
  → 캔버스/속성/타임라인 편집
  → 자동 저장 또는 저장
  → MP4 내보내기
  → 다운로드
```

## 화면별 관찰 명세

### 대시보드

- 영상 링크 입력과 파일 업로드가 같은 시작점에 있다.
- 샘플 결과와 최근 프로젝트가 별도 진입점으로 제공된다.
- 분석 중에는 현재 상태와 진행률을 사용자가 확인할 수 있어야 한다.
- 실패 시 입력 문제인지 다운로드 문제인지 구분된 안내가 필요하다.

### 결과 화면

- 여러 생성 클립이 점수순 목록으로 보인다.
- 선택한 클립은 목록, 세로형 미리보기, 제목, 점수, 자막 정보에 동시에 반영된다.
- 점수는 종합·훅·주제 연결·흐름·몰입·마무리 평가로 분리된다.
- 미리보기는 실제 생성 영상이어야 하며 원본 구간의 단순 카드가 아니다.
- 자막은 선택 클립의 실제 시간 구간과 연결된다.
- 편집·공유·다운로드는 현재 선택된 클립을 대상으로 한다.

### 편집기

- 좌측: 시간 구간별 자막/스크립트 목록
- 중앙: 9:16 캔버스와 실제 영상 미리보기
- 우측: 선택 객체의 편집·스타일·위치 속성
- 하단: 영상 트랙, 자막 트랙, 재생 위치, 구간 추가, 확대/축소
- 제목을 수정하면 캔버스와 결과 내보내기에 모두 반영된다.
- 자막 세그먼트를 선택하면 재생 위치와 우측 편집 대상이 함께 바뀐다.
- 실행 취소/다시 실행은 재생 위치뿐 아니라 제목·자막·레이어·구간을 복원한다.

## 상태 전이

| 상태 | 진입 | 화면 요구사항 | 종료 |
|---|---|---|---|
| `needs-source` | 빈 프로젝트 | 입력 안내 | 파일/링크 입력 |
| `downloading` | 공개 영상 링크 제출 | 진행률·중복 방지·실패 안내 | 다운로드 완료/실패 |
| `analyzing` | 분석 시작 | 분석 중 상태·재진입 방지 | 완료/실패 |
| `completed` | 클립 생성 완료 | 실제 클립 목록·미리보기 | 클립 선택 |
| `editing` | 편집기 진입 | 선택 클립·자막·타임라인 | 저장/내보내기 |
| `exporting` | 내보내기 클릭 | 렌더링 상태 | 다운로드/실패 |
| `failed` | 처리 실패 | 원인·재시도 안내 | 재시도 |

## 클린룸 경계

- 관찰된 화면 구조, 사용자 동작, 상태 전이만 구현 근거로 사용한다.
- FikaClip의 코드, 번들, 비공개 API, 이미지, 로고, 내부 데이터는 복사하지 않는다.
- 관찰되지 않은 AI 동작은 실제 구현 전까지 미확인으로 표시한다.
