# 통합 검증 실행 기록

## 실행 범위

- 최신 로컬 서버를 8787에서 재시작
- 결과 화면에서 완료 프로젝트 로딩
- 5개 결과 클립 확인
- 두 번째 클립 선택
- 선택 클립 편집기 진입
- 내보내기 실행
- 생성된 MP4를 FFprobe로 확인

## 미통과/보류

- 기존 프로젝트에 저장된 오래된 자막은 재분석 전까지 인코딩이 깨져 보일 수 있다.
- FikaClip의 단어 단위 자막 편집, 다중 클립 순서/삭제/전환, 고급 제목 스타일과의 최종 동등성은 아직 미통과다.
- 따라서 이 실행은 8단계의 기본 내보내기 통과를 증명하지만 전체 100%를 의미하지 않는다.
