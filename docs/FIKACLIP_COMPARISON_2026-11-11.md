# FikaClip 최종 비교 기록

## 2026-11-11 대시보드 재관찰 (REA)

**근거:** 로그인된 외부 FikaClip 대시보드의 수동 REA 화면·접근성 관찰 (`ev_9f744fe076e64d21160ffec98b73a7939af6158b1557fc44113ae4f43b26cb29`, 스크린샷 `ev_6e8c76cd383717145c81597e6cadfed718e3957a62a77f9bbc8a786aa9f3211e`). 브라우저의 코드·번들·비공개 응답은 관찰하거나 사용하지 않았다.

| 관찰된 사용자 구조 | SkyClip 조치 | 상태 |
|---|---|---|
| 영상 파일 선택/드롭과 `youtube-link-input`이 대시보드 진입점으로 함께 존재 | 파일 업로드·드롭과 직접 파일 URL 분석을 단일 제작 영역으로 재구성 | 구현 |
| 이미지·영상·배경 음악·효과음 제작 진입점이 보임 | 실제 에셋 보관함으로 연결되는 빠른 제작 도구를 대시보드에 제공 | 구현 |
| `내 영상`과 샘플 영상·가이드/템플릿 안내가 공존 | 최근 완료 로컬 프로젝트와 실제 샘플 결과 진입점을 대시보드 하단에 제공 | 구현 |
| 크레딧/업그레이드/계정은 로그인·결제 영역 | 범위 밖: 회원·결제 기능은 독립 서비스에 구현하지 않음 | 제외 |

### 이번 UI 구현의 기준

- **Visual thesis:** 밝고 절제된 작업 화면에서 ‘새 영상 만들기’가 첫 행동으로 명확히 보이도록 한다.
- **Content plan:** 영상 시작 → 에셋 준비 → 최근 프로젝트 재진입 → 실제 샘플 결과 확인.
- **Interaction thesis:** 파일 드롭 영역 강조, 최근 프로젝트 즉시 결과 복원, 에셋 도구에서 라이브러리로 즉시 이동.

## 2026-11-11 결과·편집기 재관찰 (REA)

**근거:** 샘플 영상 결과 화면의 실제 조작 및 편집 진입 관찰 (`ev_74e14e671bfc39dadc9e704184237d4f0adc13f6b9aeaf5dd4d629dfdc275e6d`, `ev_545c57a6af1014b9171933ab4414be6943438a1dfae3693485f4bc1944363ea0`, `ev_40568250ef29a45eeef61dfa0782ef51b9f23ec2a657e7e3104453c5324e0fa3`, `ev_c3725d24864e1852c028aabe67d1348722bba5dcced0f12280c036a310e8dd85`). 샘플 결과를 열고 첫 클립의 편집 진입만 수행했으며, 저장·내보내기·유료 생성은 실행하지 않았다.

| 관찰된 사용자 흐름 | SkyClip 조치 | 상태 |
|---|---|---|
| 결과는 점수·제목·길이가 있는 좌측 후보 레일과 전체 클립 카드의 반복 목록으로 구성됨 | 후보 레일 + 실제 미리보기·점수·자막·편집/다운로드 액션을 가진 결과 카드 흐름으로 재구성 | 구현 |
| 카드마다 제목 편집·AI 제목 재생성·자막 교정·편집 진입이 제공됨 | 결과 카드에서 클립 선택 후 실제 편집기 진입·다운로드·클립별 제목 저장을 연결. 제목 재생성은 현재 클립 자막 기반 로컬 후보 생성이며 외부 AI 모델 동등성은 없음 | 구현 |
| 편집기는 자막/스크립트, 캔버스, AI 도구·속성, 다중 트랙 타임라인을 한 작업 화면에 유지 | SkyClip 편집기의 자막-캔버스-속성-타임라인 동시 배치가 관찰 근거와 일치하는지 다음 단계에서 패널별 조작으로 검증 | 비교 진행 중 |

### 확인된 다음 차이

- 결과 화면은 점수·길이·원본 순서 정렬과 점수 80 이상·45초 이하의 실제 클립 필터를 제공한다. FikaClip의 전체 필터 조건 체계와는 아직 동등하지 않다.
- FikaClip의 카드별 상세 평가 설명과 고품질 의미 분석은 SkyClip의 로컬 휴리스틱과 동등하지 않다.
- 편집기 트랙별 표시·잠금·숨김과 FikaClip의 4:3 캔버스·맞춤 동작은 개별 조작 관찰과 구현 검증이 남아 있다.

## 2026-11-11 편집기 상태 연결 보완

**근거:** 로그인된 외부 FikaClip 편집기의 수동 REA 재관찰 (`ev_e4369b2cdb01a1a70fd923690622905eaeaa4a290cbc9d409b5a07fd883ad9c0`) 및 앞선 편집기 화면 증거. REA의 제어 시나리오가 외부 페이지 응답 대기 상태로 완료되지 않아, 상세/개요 전환 후의 내부 상태는 관찰 완료로 판정하지 않는다.

- SkyClip의 자막 패널 `상세`/`개요`는 각각 시간·단어 단위 자막 목록과 전체 스크립트 요약으로 실제 전환된다.
- 캔버스 비율은 9:16·1:1을 프로젝트 편집 상태에 저장하고, 다음 내보내기에도 같은 비율로 실제 적용한다. 4:3은 현재 렌더러가 지원하지 않으므로 선택지로 표시하지 않았다.
- 메인 영상 트랙의 음소거는 내보내기 오디오 맵에도 적용된다. 기존에는 UI 상태만 바뀌고 MP4 음원에는 반영되지 않는 결함이었다.
- 결과 카드의 제목 편집과 자막 기반 제목 후보는 클립별 제목 API에 저장되며, 이후 프로젝트 재진입 시 자동 생성 제목으로 덮어쓰지 않는다.
- 타임라인 트랙은 숨김·잠금 상태를 저장한다. 숨긴 자막 트랙은 편집 캔버스·번트 자막·자막 트랙 내보내기에서 제외되고, 잠긴 트랙은 재정렬·음소거·에셋 변경을 막는다.

**검증:** `npm run test:e2e`, `npm run test:acceptance` 모두 통과. 이 검증은 실제 클립·자막·MP4 다운로드를 포함하지만, FikaClip과의 화면 픽셀 일치 또는 의미 분석 품질 동등성을 증명하지는 않는다.

## 관찰 범위

로그인된 FikaClip 편집기와 로컬 SkyClip 편집기를 같은 브라우저 세션에서 접근성 트리와 화면 흐름 기준으로 비교했다.

## 남은 차이

- FikaClip의 외부 모델 수준 의미 기반 하이라이트와 점수 모델은 로컬 의미 단서·오디오·장면 휴리스틱과 동일하지 않다. SkyClip은 문장 완결·핵심 단서·어휘 다양성·반응 표현을 추가 반영했지만, 동일성은 검증하지 않는다.
- FikaClip의 다중 트랙별 정밀 크기·불투명도 조절과 훅 인트로 삽입은 아직 완전 동등하지 않다. SkyClip은 현재 트랙별 이미지·영상·오디오 에셋 연결, 시작·종료 시점과 X/Y 위치의 실제 합성, 선택 구간 사이의 실제 영상·오디오 크로스페이드를 렌더링한다.
- 외부 AI 번역/이미지/음성/음악 생성 API는 연결 경계만 정의되어 있다.
- 자막 교정은 로컬 정규화 API를 실제 연결했다. 번역 UI는 환경변수 기반 외부 API를 호출하고 반환 자막을 VTT·선택 클립·내보내기에 동기화하며, 공급자가 없으면 실패를 명시한다.
- 생성형 미디어 도구 버튼은 `SKYCLIP_MEDIA_API_URL`을 호출하며, 결과 에셋을 반환하는 공급자일 때 현재 편집에 연결한다.
- 다중 트랙·구간별 전환·자막/제목 애니메이션은 아직 FikaClip과 완전 동등하지 않다.
- FikaClip과 픽셀 단위로 동일한 UI가 아니라, 사용자 흐름과 조작 목적을 독립 구현한 상태다.
