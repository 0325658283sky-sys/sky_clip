# FikaClip ↔ SkyClip 중간 비교 결과

## 비교 범위

로그인된 FikaClip 편집기와 로컬 SkyClip 편집기를 같은 사용자 관점에서 접근성 트리와 화면으로 비교했다. 이 문서는 최종 통과 판정이 아니라 다음 구현 우선순위를 정하기 위한 중간 검증이다.

## 관찰된 차이

| 영역 | FikaClip 관찰 | SkyClip 현재 | 다음 보완 |
|---|---|---|---|
| 자막 패널 | 단어 단위 세그먼트, 구간 정렬, 구간 재생성 | 구간 단위 목록과 직접 문구 편집 | 단어 단위 모델과 구간 재생성 경계 추가 |
| 제목 패널 | 편집·스타일·위치 탭, 폰트·컬러·크기·그림자·배경·외곽선 | 제목·자막·텍스트 속성 기본 패널 | 스타일/위치 속성의 실제 렌더링 확대 |
| 캔버스 | 9:16, 제목/자막 직접 선택, 확대/축소 | 9:16, 실제 영상과 제목/자막 오버레이 | 캔버스 객체 선택·이동·크기 조절 |
| 타임라인 | 자막 트랙·메인 영상 트랙·다중 클립 정렬·삭제·전환·줌 | 영상/자막 트랙, 구간 추가, 자막 드래그, 구간 표시 | 컷 삭제·순서 변경·전환 트랙·줌 |
| 저장 | 자동 저장 토글, 저장/내보내기 상태 | 로컬 자동 저장 표시, 저장/내보내기 호출 | 실제 저장 상태 표시와 재진입 검증 |
| AI 도구 | 제목 재생성, 자막, 텍스트, 요소, 미디어, 전환, 효과 등 | 일부 도구가 실제 레이어·상태·렌더링에 연결 | 외부 AI가 필요한 도구는 경계 명시 후 로컬 기능 완성 |

## 판정

- 1~2단계의 분석·명세 방향은 유지한다.
- 6~8단계에서 먼저 단어 단위 자막, 다중 클립 트랙, 제목 스타일 속성을 보완한다.
- 이 문서의 모든 “다음 보완” 항목이 실제 영상으로 통과하기 전에는 100%로 판정하지 않는다.
