# FikaClip 최종 비교 기록

## 2026-11-11 비교 기준·분석 품질 회귀 검증

**REA 근거:** 로그인된 FikaClip의 현재 편집 대상 URL이 다시 확인되었다 (`ev_5fcff9cc68585d153711258aeff127cb2955c9ecb290af4b7b5d83fbb3f9a4c4`). 이 증거는 편집 대상의 존재와 URL만 확인하며, 버튼별 결과·점수 산식·생성 모델을 확인한 증거는 아니다.

- SkyClip의 후보 선택과 제목 생성은 `lib/highlight-quality.mjs`로 분리했다. `npm run test:quality`는 100초 영상의 전체 시간축에 후보를 분산하고 중복 시작점을 제거하는지, 영상이 짧을 때 단일 0초 후보로 안전하게 폴백하는지, 자막이 비어 있거나 의미 없는 경우 `핵심 장면 N`으로 제목을 폴백하는지를 검사한다.
- 실제 미디어 경로는 별도로 `npm run test:e2e`에서 FFmpeg 클립·편집 상태·MP4 다운로드를 검증한다. 짧은 E2E 영상은 미디어 처리 경로 확인용이며, 장편 영상의 의미 품질을 입증하는 데이터셋은 아니다.
- 따라서 이번 검증은 SkyClip의 **후보 중복 및 제목 공백 회귀 방지**를 보장하지만, FikaClip의 의미 기반 하이라이트 모델이나 점수 품질과 동등하다고 판정하지 않는다. 그 판단에는 동일한 여러 장편 영상과 실제 FikaClip 결과를 나란히 평가하는 추가 관찰이 필요하다.

## 2026-11-11 에셋·릴리스 경계 검증

**REA 근거:** 로그인된 FikaClip 편집 대상은 현재도 편집 URL로 열려 있다 (`ev_b225968e3392ee8fd5b12033c171b3d51f0fdab3a91326440ca98b581f4b1dc6`). 이 수동 관찰은 FikaClip 내부 에셋 교체/삭제의 상태 전이를 증명하지 않는다.

- SkyClip은 선택한 트랙에 에셋을 연결·교체하고, 정밀 편집 패널에서 연결을 해제할 수 있다. 에셋 보관함에서 삭제하면 모든 로컬 프로젝트의 해당 `assetId` 참조를 함께 해제해 고아 참조를 남기지 않는다.

- 번역/생성형 미디어 기능은 공급자 URL이 설정된 경우에만 실제 API를 호출한다. 현재 저장소에는 특정 공급자 URL·키를 포함하지 않으므로, 외부 AI 결과 품질이나 재시도 성공 경로는 아직 릴리스 통과로 판정하지 않는다.

## 2026-11-12 REA 재관찰 상태

REA가 설정된 Chrome 원격 디버깅 엔드포인트 `127.0.0.1:9222`에 연결을 시도했으나 도달하지 못했다. 따라서 이번 작업에서는 FikaClip 화면·버튼 상태 전이를 새로 관찰하지 않았고, 기존 관찰을 확대 해석하지 않는다. 상세 비교를 재개하려면 로그인된 Chrome을 원격 디버깅 포트와 함께 다시 실행해야 한다.

로컬 SkyClip은 이와 독립적으로 E2E에서 제목 회전값 저장, 템플릿·트랙·에셋 연결/삭제, AI 공급자 미설정 오류 경계, 실제 `960x720` MP4 다운로드를 다시 통과했다. 이는 SkyClip의 회귀 검증이며 FikaClip 동등성 판정은 아니다.

- 이 구현은 SkyClip의 독립 렌더링 검증이다. REA 디버그 연결이 복구되기 전에는 FikaClip 편집기와 같은 조작 결과라고 판정하지 않는다.

- SkyClip의 자막 패널 `상세`/`개요`는 각각 시간·단어 단위 자막 목록과 전체 스크립트 요약으로 실제 전환된다.

- 메인 영상 트랙의 음소거는 내보내기 오디오 맵에도 적용된다. 기존에는 UI 상태만 바뀌고 MP4 음원에는 반영되지 않는 결함이었다.
- 결과 카드의 제목 편집과 자막 기반 제목 후보는 클립별 제목 API에 저장되며, 이후 프로젝트 재진입 시 자동 생성 제목으로 덮어쓰지 않는다.
- 타임라인 트랙은 숨김·잠금 상태를 저장한다. 숨긴 자막 트랙은 편집 캔버스·번트 자막·자막 트랙 내보내기에서 제외되고, 잠긴 트랙은 재정렬·음소거·에셋 변경을 막는다.

**검증:** `npm run test:e2e`, `npm run test:acceptance` 모두 통과. 이 검증은 실제 클립·자막·MP4 다운로드를 포함하지만, FikaClip과의 화면 픽셀 일치 또는 의미 분석 품질 동등성을 증명하지는 않는다.

## 관찰 범위

로그인된 FikaClip 편집기와 로컬 SkyClip 편집기를 같은 브라우저 세션에서 접근성 트리와 화면 흐름 기준으로 비교했다.

## 남은 차이

- FikaClip의 외부 모델 수준 의미 기반 하이라이트와 점수 모델은 로컬 의미 단서·오디오·장면 휴리스틱과 동일하지 않다. SkyClip은 문장 완결·핵심 단서·어휘 다양성·반응 표현을 추가 반영했지만, 동일성은 검증하지 않는다.
- FikaClip의 다중 트랙별 정밀 크기·불투명도 조절과 훅 인트로 삽입은 아직 완전 동등하지 않다. SkyClip은 현재 트랙별 이미지·영상·오디오 에셋 연결, 시작·종료 시점과 X/Y 위치의 실제 합성, 선택 구간 사이의 실제 영상·오디오 크로스페이드를 렌더링한다.
- 외부 AI 번역/이미지/음성/음악 생성 API는 연결 경계만 정의되어 있다.
- 자막 교정은 로컬 정규화 API를 실제 연결했다. 번역 UI는 환경변수 기반 외부 API를 호출하고 반환 자막을 VTT·선택 클립·내보내기에 동기화하며, 공급자가 없으면 실패를 명시한다.
- 생성형 미디어 도구 버튼은 `SKYCLIP_MEDIA_API_URL`을 호출하며, 결과 에셋을 반환하는 공급자일 때 현재 편집에 연결한다.
- 다중 트랙·구간별 전환·자막/제목 애니메이션은 아직 FikaClip과 완전 동등하지 않다.
- FikaClip과 픽셀 단위로 동일한 UI가 아니라, 사용자 흐름과 조작 목적을 독립 구현한 상태다.
